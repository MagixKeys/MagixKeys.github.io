Magix Keys Dongle - DIY Web-Flasher

With this tool you can easily program or update an M5Stack Atom S3 Lite development kit to the latest firmware version directly from your browser, if you are using Chrome or Edge with JavaScript being turned on. If you have installed the esptool.py on your computer, you can alternatively use this tool. In this case you need to press the button "Use esptool.py" for further instructions.

In order to prepare the M5Stack Atom S3 Lite kit for flashing, you must connect it via USB to your computer and switch it to bootloader mode by holding down the button on the side for a few seconds until it lights up green and then release the button.

After that, press the button "Connect" below and select the serial port of your M5Stack Atom S3 Lite development kit in the dialog that shows a list of currently connected serial devices. If you are unsure, which entry belongs to the M5Stack Atom S3 Lite, you can hold down the button on the side again while the selection dialog is open. The respective entry will then disappear and reappear, when you release the button as soon it lights up green again.

If you have esptool.py locally installed on your computer, you can use this tool to program your M5Stack Atom S3 Lite dev kit with the Magix Keys Dongle Firmware by following these steps:

  1. Download the files boot.bin and MagixKeysDongle.bin
  2. Hold the button on the side of the dongle pressed until it lights up green in order to enter bootloader mode.
  3. Execute the following command (replace COM4 with the applicable port on your computer):

    python esptool.py -p COM4 write_flash 0x0 boot.bin 0x20000 MagixKeysDongle.bin

  4. Start the firmware by either short-pressing the button on the side of the dongle or unplugging and replugging the dongle. After that, short-press the Magix Keys Dongle's main button. Now the main indicator light is supposed to flash three times in blue (if not connected to the app) or green (if connected)
  5. If you flash the dongle for the first time, you need to install the Magix Keys Dongle License by establishing a connection from the Magix Keys App and following the instructions there.
